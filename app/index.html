Module 01 / Records

Unit Registration

Find an existing unit by VIN or stock number before registering a new one. No service visit or RO is created automatically.

Connection configuration required

Set the public Supabase URL and publishable key in app/config.mjs, then serve this repository through a local or preview web server. Never put a service-role key in frontend configuration.

Employee sign-in

Sign in with an existing, authorized Supabase Auth account. Memberships must be provisioned by a trusted administrator.

Find a unit

Exact VIN or stock number lookup. Search before registering to avoid duplicates.

Authorized organization records

Register new unit

Any authorized branch employee may create a minimal unit record. A Service Writer can complete intake later.

No visit created

At least VIN or stock number is required. Confirm existing matches before creating another record.
